# TAKEME — internal store privacy disclosure inventory

Audit: 3 October 2026; source baseline `ac17c5130718b9c8c631191be7e0a2e028761c45`. **Internal developer document. Not a submitted Apple/Google form, privacy label, or public policy.** No production access was used. The current repository is the web implementation; native SDK/manifests, permissions and release binaries must be audited separately before store submission.

“Collected” means implemented transmission/storage in the app or its verified providers. A pseudonymised user reference is still potentially linked data, not automatically anonymous. “Private” means unavailable to ordinary unrelated users; authorised administration/provider access is separate. Google service-provider transfer exceptions must be evaluated against actual contracts and SDK practices, not treated as no collection. Apple and Google use different category/purpose definitions.
